01. L'Image Source du Tourbillon Multicolore

Contrairement à une illusion d'optique purement vectorielle, le site utilise une image texture 800×800px représentant un fluide liquide aux reflets irisés néon (rose bonbon, cyan, magenta, violet). Elle est redimensionnée à 400% dans le CSS pour que son centre fluide s'enroule de façon organique lors des rotations :

02. Codes Prêts à l'Emploi (HTML & CSS)

Choisissez la solution qui convient à votre projet :

💡 Comment fonctionne l'effet original ?
1. Le masque de découpe : Le conteneur parent possède overflow: hidden et un border-radius.
2. L'agrandissement x4 : La couche interne mesure width: 400% et aspect-ratio: 1, centrée au milieu via transform: translate(-50%, -50%). Ce zoom très fort permet d'éviter que les bords de l'image n'apparaissent lors de la rotation.
3. L'animation combinée : L'animation spectral ne fait pas qu'une simple rotation : elle effectue un tour complet (0° à 360°) tout en faisant osciller l'échelle entre 0.8 et 2.0 (à 25% et 75%). Cette pulsation donne l'illusion de vagues liquides qui s'enroulent et gonflent. 
<!-- Structure HTML -->
<div class="tourbillon-card">
  <div class="tourbillon-anim"></div>
  <div class="card-content">
    <h3>Mon Titre</h3>
    <p>Contenu par-dessus le tourbillon</p>
  </div>
</div>

<style>
/* 1. Cadre parent */
.tourbillon-card {
  position: relative;
  width: 250px;
  height: 350px;
  border-radius: 16px;
  overflow: hidden; /* Découpe l'image agrandie */
  background: #140826;
  border: 1px solid rgba(255, 255, 255, 0.1);
  box-shadow: 0 15px 35px rgba(0, 0, 0, 0.7);
}

/* 2. Couche interne agrandie à 400% */
.tourbillon-anim {
  position: absolute;
  width: 400%;
  aspect-ratio: 1 / 1;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}

.tourbillon-anim::after {
  content: '';
  position: absolute;
  inset: 0;
  background-position: center;
  background-repeat: no-repeat;
  background-size: 100%;
  /* Image texture du tourbillon multicolore */
  background-image: url('spectral-fx2.jpg');
  /* Animation CSS originale */
  animation: spectral 10s linear infinite;
}

/* 3. L'animation CSS originale avec rotation + scale */
@keyframes spectral {
  0%   { transform: translate3d(0, 0, 0) rotate(0deg) scale(0.8); }
  25%  { transform: translate3d(0, 0, 0) rotate(90deg) scale(2); }
  50%  { transform: translate3d(0, 0, 0) rotate(180deg) scale(0.8); }
  75%  { transform: translate3d(0, 0, 0) rotate(270deg) scale(2); }
  100% { transform: translate3d(0, 0, 0) rotate(360deg) scale(0.8); }
}

/* 4. Contenu par-dessus */
.card-content {
  position: relative;
  z-index: 10;
  color: #fff;
  padding: 1.5rem;
}
</style>
💡 Pourquoi la version 100% CSS Pur ?
Elle ne nécessite aucun fichier image à stocker. Elle utilise un dégradé conique (conic-gradient) passant par les couleurs de l'arc-en-ciel néon, associé à un filtre de flou intense (blur(28px)) et un cycle dynamique de saturation et de teinte (hue-rotate). 
<!-- Structure HTML (Zéro image externe) -->
<div class="vortex-pure-card">
  <div class="vortex-swirl"></div>
  <div class="vortex-vignette"></div>
  <div class="card-content">
    <h3>100% CSS Pur</h3>
  </div>
</div>

<style>
.vortex-pure-card {
  position: relative;
  width: 250px;
  height: 350px;
  border-radius: 16px;
  overflow: hidden;
  background: #0c0814;
  border: 1px solid rgba(255, 255, 255, 0.1);
}

.vortex-swirl {
  position: absolute;
  width: 320%;
  aspect-ratio: 1 / 1;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
  border-radius: 50%;
  /* Dégradé conique multicolore */
  background: conic-gradient(
    from 0deg,
    #ff0080,
    #7928ca,
    #0070f3,
    #00dfd8,
    #43e97b,
    #fa709a,
    #fee140,
    #ff0080
  );
  filter: blur(28px) saturate(190%);
  animation: pure-spin 8s linear infinite, hue-shift 12s ease-in-out infinite;
}

.vortex-vignette {
  position: absolute;
  inset: 0;
  background: radial-gradient(circle at center, transparent 35%, rgba(12, 8, 20, 0.75) 75%, #0c0814 100%);
  mix-blend-mode: multiply;
  pointer-events: none;
}

@keyframes pure-spin {
  0%   { transform: translate(-50%, -50%) rotate(0deg) scale(0.9); }
  50%  { transform: translate(-50%, -50%) rotate(180deg) scale(1.3); }
  100% { transform: translate(-50%, -50%) rotate(360deg) scale(0.9); }
}

@keyframes hue-shift {
  0%, 100% { filter: blur(28px) saturate(190%) hue-rotate(0deg); }
  50%      { filter: blur(22px) saturate(230%) hue-rotate(90deg); }
}
</style>
💡 La variante Double Tourbillon Contre-Rotatif :
Présente en esquisse dans le code source d'origine sous le nom de spectral-reverse, cette technique utilise deux pseudo-éléments (::before et ::after). L'un tourne dans le sens des aiguilles d'une montre et l'autre en sens inverse avec mix-blend-mode: screen. Le mélange lumineux crée une texture encore plus dense et chatoyante. 
<!-- Structure HTML Double Tourbillon -->
<div class="dual-card">
  <div class="dual-swirl"></div>
  <div class="card-content">
    <h3>Double Swirl</h3>
  </div>
</div>

<style>
.dual-card {
  position: relative;
  width: 250px;
  height: 350px;
  border-radius: 16px;
  overflow: hidden;
  background: #0f0a1c;
  border: 1px solid rgba(255, 255, 255, 0.12);
}

.dual-swirl {
  position: absolute;
  width: 400%;
  aspect-ratio: 1 / 1;
  left: 50%;
  top: 50%;
  transform: translate(-50%, -50%);
}

.dual-swirl::before,
.dual-swirl::after {
  content: '';
  position: absolute;
  inset: 0;
  background-position: center;
  background-repeat: no-repeat;
  background-size: 100%;
  background-image: url('spectral-fx2.jpg');
}

/* Couche 1 : sens horaire */
.dual-swirl::before {
  animation: spectral-cw 10s linear infinite;
  opacity: 0.85;
}

/* Couche 2 : sens anti-horaire avec mode de fusion screen */
.dual-swirl::after {
  animation: spectral-ccw 14s linear infinite;
  mix-blend-mode: screen;
  opacity: 0.75;
}

@keyframes spectral-cw {
  0%   { transform: rotate(0deg) scale(0.8); }
  25%  { transform: rotate(90deg) scale(2); }
  50%  { transform: rotate(180deg) scale(0.8); }
  75%  { transform: rotate(270deg) scale(2); }
  100% { transform: rotate(360deg) scale(0.8); }
}

@keyframes spectral-ccw {
  0%   { transform: rotate(360deg) scale(1.6); }
  50%  { transform: rotate(180deg) scale(0.9); }
  100% { transform: rotate(0deg) scale(1.6); }
}
</style>
