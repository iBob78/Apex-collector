Animations Carte "Fused" & Spin 1080°

Dans ce second code source (carte Dania Vega), la carte utilise le système .wrapper-card.common.shimmy.fused.fused-active. Il combine une aura néon électrique en défilement, un voile holographique irisé, des scintillements animés, une oscillation 3D et une animation de rotation 1080°.

Palette Rareté :
Dania Vega
Common Fused
✨ Les 5 Couches d'Animations Actives
1

Aura & Contour Néon Électrifié (.fused + @keyframes steam)

Généré par .front:before et .front:after. Le dégradé background-size: 400% défile en continu sur 20s. La couche :after a filter: blur(1.2em), produisant un halo énergétique rayonnant.

2

Balayage Holographique Irisé (.fused-active:before + @keyframes hologradient)

Un flash diagonal cyan et magenta passe en boucle avec mix-blend-mode: color-dodge, donnant à la carte l'aspect d'une carte brillante de collection (foil/holographique).

3

Paillettes Scintillantes (.fused-active:after + @keyframes holosparkle)

Une nappe d'étoiles scintillantes (sparklez.gif) avec mix-blend-mode: color-dodge qui respire avec des variations d'opacité entre 50% et 85%.

4

Balancement 3D & Rayon de Lumière (.shimmy + .shine)

La carte oscille doucement dans l'espace 3D (rotateY(18deg) skewX(2.5deg)), pendant qu'un rayon lumineux blanc (.shine) traverse la carte toutes les 6 secondes.

5

Transformation 3D Spin 1080° (.spinincard1080deg)

Déclenchée au clic (bouton ci-dessus) : la carte réalise 3 tours complets à 360° (1080°) en perspective 3D sur 2 secondes pour révéler son déverrouillage ou son skin Fullart.

💡 L'astuce du contour néon animé "Steam" :
Le secret réside dans le background-size: 400% sur le pseudo-élément ::before, couplé à un second pseudo-élément ::after identique mais muni d'un filter: blur(...). Le déplacement continu du dégradé (de 0 à 400%) donne cette impression de courant électrique liquide qui tourne autour du cadre. 
/* Effet Aura Néon Steam Minimal */
.neon-box {
  position: relative;
  width: 250px;
  height: 350px;
  background: #120c22;
  border-radius: 16px;
}

.neon-box::before,
.neon-box::after {
  content: '';
  position: absolute;
  inset: -4px;
  border-radius: 20px;
  background: linear-gradient(45deg, #d4ffa7, #77e203, #1e0322, #6eff78, #15c421);
  background-size: 400%;
  z-index: -1;
  animation: steam 20s linear infinite;
}

/* Le flou qui crée la lueur rayonnante */
.neon-box::after {
  filter: blur(16px);
  opacity: 0.8;
}

@keyframes steam {
  0%, 100% { background-position: 0 0; }
  50%      { background-position: 400% 0; }
}
💡 Comment fonctionne le Spin 1080° :
La classe .spinincard1080deg applique 3 tours complets à 360° (soit 1080°) sur l'axe Y en 2 secondes, avec un léger skewX pour donner du relief et de la torsion à la carte durant la rotation. 
/* Animation de rotation 1080° */
.spinincard1080deg {
  transition-duration: 0.25s;
  animation: spinincard1080deg 2s ease-in-out forwards;
}

@keyframes spinincard1080deg {
  0% {
    transform: rotateY(0deg) skewX(2deg);
  }
  100% {
    transform: rotateY(1080deg) skewX(1deg);
  }
}
